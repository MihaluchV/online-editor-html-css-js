# online-editor-html-css-js
# Онлайн-редактор HTML, CSS, JS

Однофайловий онлайн-редактор для навчання веб-технологіям. Працює повністю в браузері, без сервера.

## Можливості
- Дерево файлів і папок (створення, перейменування, копіювання, вирізання, вставка, видалення, перетягування)
- Редактор із підсвічуванням, нумерацією рядків, згортанням блоків, вертикальними лініями
- Emmet, автодоповнення, автозакриття тегів і дужок, одночасне перейменування парних тегів
- Пошук і заміна (у файлі та в проєкті), підкреслення помилок і панель помилок
- Перегляд сторінки з вкладками, історією, консоллю, повноекранним режимом
- Збереження проєкту в браузері, імпорт і експорт у ZIP
- Шаблони проєкту, теми, налаштування розміру шрифту

## Запуск
Відкрийте `index.html` у браузері або опублікуйте репозиторій через GitHub Pages.

Проєкт зберігається у браузері користувача (IndexedDB / localStorage). Для перенесення використовуйте кнопки «Зберегти» (ZIP) та «Відкрити ZIP».
